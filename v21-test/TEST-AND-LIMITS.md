# v21 확인 결과와 남은 선택

## 직접 확인한 것

실제 Chromium 기반 앱 내 브라우저, 393×851 및 360×800 뷰포트에서 확인했습니다. 실제 Android 단말·마이크 하드웨어 검증과 운영 HTTPS 배포는 하지 않았습니다.

| 시나리오 | 결과 |
|---|---|
| A 검색에 없는 전복 추가 | 검색어 재입력 없이 추가, 새로고침 유지 |
| B 전복·콩나물·어묵 우선 | 모든 표시 후보에 세 재료의 음식이 포함됨 |
| C 다른 추천 | 전복 조건 유지, 주메뉴가 다른 조합 표시 |
| D 음식 하나 변경 | 전복간장조림→전복버터구이, 쌀밥·어묵국·콩나물무침 유지, 구매 재료 간장→버터 갱신 |
| E 실제 기록 | 돼지국밥·바나나·토마토리조또를 한 문장으로 구분·저장. 단백질/지방/무기질에 돼지고기, 비타민에 토마토·바나나 표시 |
| F v20 데이터 | 가상 v20 저장 상태에서 기존 프로필·재료·확정 계획·과거 끼니·하루 원문·체크·완료 기록 보존 |
| G 모바일 | 두 뷰포트에서 주요 동작 확인, 가로 넘침 없음. Wi-Fi 주소에서도 음식 ID 생성/저장/재접속 성공 |
| H 기관/음성/알림 | 9/22와 10/15 일괄 확인·저장/오늘 기관 식사 반영. 기기 내 한국어 음성이 없는 환경에서는 시작하지 않고 안내. 미구현 OCR/push를 기능으로 표시하지 않음 |

추가: 아이 정보 저장·기관 이용 해제 후 집 세 끼 전환 확인. 최종 새 브라우저 세션에서 실행 오류 없음. 모델 회귀 검사 15개 통과: 전 재료 조건, 불명 재료 공개, 국 중복 방지, 단일 음식 수정/해동/구매 의존성, 보수적 영양 분류, 자연어 오류 처리, 장기 기관 일정, 실제/예정 분리, v2/v3 보존, 복원/되돌리기, 동시 편집 충돌.

검사 실행: Node.js가 설치된 PC에서 `node tests/test-model.cjs`.

## 지금 되는 것과 안 되는 것

- 빠른 기록은 제한된 한국어 규칙 해석입니다. 날짜가 섞이거나 부정 표현이 있으면 확인을 요청합니다. 자유 대화형 AI는 아닙니다. 시간 없는 간식은 오후로 제안하고 사용자가 바꿀 수 있습니다.
- 기관 입력은 한 줄 한 날짜의 텍스트와 세 열 구분 형식입니다. 종이/사진 표의 행과 열을 자동 읽는 OCR은 없습니다. 임의의 표를 이해한다고 주장하지 않습니다.
- 음성은 `processLocally=true`, 한국어 언어팩 `available`인 경우만 실행합니다. 이 시험 환경에서는 언어팩이 없어 실제 음성→문자 성공은 미검증입니다. HTTP Wi-Fi 미리보기는 보안 컨텍스트가 아니므로 음성/PWA 설치/오프라인은 정식 HTTPS에서 확인해야 합니다.
- PWA manifest와 새 캐시의 모든 파일을 포함했습니다. 기존 운영 주소의 서비스 워커 업데이트와 실제 Android 설치는 배포 후 추가 확인이 필요합니다. 기록은 계속 브라우저별 localStorage입니다.

## 필요한 결정 — 현재 작업을 막지 않고 보류

1. **사진 자동 인식:** 기기 내 한국어 OCR과 표 분리 로직(개인정보 외부 전송 없음, 인식 품질 보완 필요) 또는 서버 OCR/비전 API(서버·제공사·사진 전송 및 비용 결정). 최소 구현은 사진→날짜/세 끼니 후보→지금의 확인 화면이며 실제 기록을 자동 확정하지 않습니다.
2. **폭넓은 음성 지원:** 기기 내 방식 유지 또는 브라우저/서버 원격 음성 인식 허용 여부. 음성·식사 정보 전송 범위/보관 정책/비용을 결정해야 합니다. 인식 이후 단순 구조화는 현재처럼 기기 내에서 가능합니다.
3. **앱 종료 후 알림:** 예약 서버, push 구독 보관, VAPID와 서비스 워커 처리, 권한/조용한 시간/중복 방지가 필요합니다. 어떤 서버를 사용할지와 외부에 보낼 최소 데이터를 결정해야 합니다. 행동 링크는 `?action=plan&date=YYYY-MM-DD&meal=dinner` 또는 `?action=record&date=YYYY-MM-DD`로 준비했습니다.

기술 근거: [기기 내 SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/processLocally), [언어팩 가용성 확인](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/available_static), [서버에서 보내는 Push API](https://developer.mozilla.org/en-US/docs/Web/API/Push_API).
