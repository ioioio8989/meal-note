# MEAL NOTE v21 테스트

현재 PC에서는 http://localhost:4180 에서 실행합니다. 같은 Wi-Fi에 연결한 휴대폰에서는 http://192.168.0.101:4180 을 여세요. PC가 켜져 있고 미리보기 서버가 실행 중이어야 합니다. 휴대폰 실물 연결은 아직 검증하지 않았습니다.

다시 실행하려면 이 폴더의 **Start-MEAL-NOTE.cmd**를 더블클릭하고, 뜨는 창의 Mobile 주소를 휴대폰에서 여세요. Node.js가 필요하며 현재 작업 PC에는 설치되어 있습니다. IP는 Wi-Fi 환경에 따라 바뀔 수 있습니다.

이 주소는 모바일 기능 확인용입니다. 홈 화면 설치·오프라인·기기 내 음성은 정식 HTTPS 배포에서 별도로 확인해야 합니다. 현재 GitHub 운영 버전은 바꾸지 않았습니다.

## 기존 기록으로 확인하기

운영 앱의 설정 → 기록 보관 → 백업 파일 저장. 테스트 주소의 설정에서 백업 파일 불러오기 → 내용 확인 → 복원. 테스트 주소는 운영 앱과 저장 공간이 달라 원래 기록에 영향을 주지 않습니다. 같은 주소·같은 브라우저로 정식 업데이트하면 기존 키와 기록을 그대로 사용합니다.

## 빠른 확인

1. 우리집 재료에서 전복을 검색해 바로 추가. 콩나물·어묵도 선택.
2. 메뉴 고르기에서 세 재료 선택 → 다른 메뉴 보기 → 마음에 드는 조합 선택.
3. 음식 하나만 바꾸기로 전복간장조림을 전복버터구이로 변경. 나머지 음식과 장보기 확인.
4. 기록 → 여러 끼니 한 번에 기록 → “아침 돼지국밥 먹었고 간식 바나나 먹었어. 저녁 토마토리조또” → 확인 → 저장.
5. 설정 → 기관 식단 등록에서 여러 날짜의 식단 텍스트를 붙여넣고 확인·저장.

사진 OCR과 앱 종료 후 알림은 미구현입니다. 음성은 기기 내 한국어 인식을 지원하는 경우에만 시작합니다. 자세한 검증/제한은 TEST-AND-LIMITS.md에 있습니다.

## 정식 배포 파일

이 폴더의 HTML, JS, CSS, PNG, manifest.webmanifest, sw.js 파일을 **기존 운영 주소의 같은 경로**에 함께 반영해야 합니다. serve.cjs와 시작 파일은 PC 미리보기 전용입니다. 테스트 중 저장한 가족 백업 JSON은 배포 파일에 넣지 마세요.
